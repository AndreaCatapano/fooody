# Mappatura contenuti per consegna al cliente / copywriter

Leggi e segui integralmente il prompt in `prompt/prompt-mappatura-contenuti.md`.

Prima di partire, sostituisci questi placeholder con i valori reali del progetto:
- `[BRANCH_PRINCIPALE]` → branch da cui creare `content-mapping` (di solito `main`)
- `[ELENCO_PAGINE]` → tutte le route presenti in `src/app/`
- `[LINK_DRIVE_CONDIVISO]` → link Google Drive o Dropbox dove il cliente caricherà le immagini

Poi esegui tutti i passi del prompt dall'analisi delle sezioni fino alla generazione di `content-map.csv` e al riepilogo finale.
